A table-based HTML signature that survives Gmail, Outlook and Apple Mail intact. Logo marks and contact icons are embedded as base64 PNGs, so it renders with no external requests and nothing to load or block.

Install

Paste, don’t import — every client rewrites the markup it stores.

Gmail web

  1. Hit Copy signature above.
  2. Open Settings → See all settings → General.
  3. Scroll to Signature, create one, and paste into the box.
  4. Save Changes at the bottom. Gmail rehosts the images on paste.

Outlook desktop

  1. Hit Copy signature above.
  2. Go to File → Options → Mail → Signatures.
  3. New, name it, then paste into the edit box.
  4. Set it as default for new mail and replies, then OK.

Apple Mail macOS

  1. Hit Copy signature above.
  2. Mail → Settings → Signatures, pick the account, press +.
  3. Clear the draft signature, then paste.
  4. Untick Always match my default message font, or Mail flattens it.

Notes

Logo marks
The Nova SBE mark is the official wordmark, cropped from the supplied logo file (the lockup’s descriptor line would be under 2px tall at this size, so the wordmark stands alone — the standard small-size treatment). scaile and A&M are still placeholders: their names set in Instrument Sans, because this environment’s network policy blocked both company sites. Swap in real files with python3 embed_logo.py scaile scaile.svg and re-run build_signature.py — marks scale to the line height keeping their own aspect ratio, and the gutter widens to fit the widest one. With images on, the marks carry the organisation names and the text lines carry only the roles; the no-images variant keeps the names in text.
Image blocking
Plenty of recipients block images by default. The No images variant carries the same content and typography with nothing to block — a safe default if you mail a lot of cold contacts.
Dark mode
Outlook and Gmail recolour dark-mode messages on their own terms. The contact icons use a mid-tone blue that stays legible either way, and the logo tiles carry their own backgrounds, so nothing disappears.
Editing
Titles, phone and links live at the top of build_signature.py, with the palette right above them. Change a value there and rebuild rather than editing the generated HTML.
